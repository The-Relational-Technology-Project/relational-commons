# Open Referral / HSDS

> Not an app — an open data standard for 'who provides what help, where' — so a community's resource directory can be maintained once and read by every tool, church, and hotline that needs it.

Every neighborhood maintains the same list a dozen times: where the food pantry is, when the clinic's open, who has beds tonight. Open Referral, founded by Greg Bloom in 2013, attacks the duplication with a standard instead of a product: the **Human Services Data Specification (HSDS)** defines how to describe services, providers, and locations so any directory can be published once and consumed everywhere — by a website, a 211 line, a case worker's tool, or an AI assistant.

It's infrastructure with real adoption: piloted in Miami's county systems, adopted across UK local government as Open Referral UK, endorsed by the 211 sector's standards body. The spec and schemas are openly published on GitHub.

**Neighborhood remix:** publish the block's mutual-aid inventory — who has a truck, a spare room, jumper cables, a Narcan kit — as a tiny HSDS-shaped dataset (with consent), so the church down the street and the next tool anyone builds can both read it without asking anyone to retype it.
