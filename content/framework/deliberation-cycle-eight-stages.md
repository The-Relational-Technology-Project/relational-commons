# The deliberation cycle: eight stages

> Metagov's governance-cycle taxonomy for deliberative tools: framing, eliciting, learning, deliberating, proposing, deciding, actuating, reflecting. Name which stage a build serves and design the hand-off to the next.

Metagov's Deliberative Tools Gallery maps "digital tools that go beyond basic voting and commenting" across a governance cycle. The eight stages, verbatim:

- **Framing**: naming the question so it can be worked on together
- **Eliciting**: gathering what people actually think and need
- **Learning**: building a shared picture before opinions harden
- **Deliberating**: weighing options together, tensions on the table
- **Proposing**: turning what was heard into concrete options
- **Deciding**: choosing together, with a method everyone can see
- **Actuating**: carrying the decision into action
- **Reflecting**: looking back at what the process taught

A block or neighborhood usually lives in the middle five: eliciting, learning, deliberating, proposing, deciding. The useful discipline for a build: say which stage(s) it serves, and design the hand-off so every stage's output is the next stage's input, with the last output landing back with people (a meeting, a flyer, a decision someone carries forward).
