# A "what we heard" report page

> Build prompt: after the listening, a report page in the Talk to the City pattern: themes with real quotes, minority views kept visible, a plain-language summary a flyer can carry back.

We ran [a poll / three living-room conversations / a listening session] on [the question] and have [the export / the notes / the transcript]. Build a "what we heard" report page in the Talk to the City pattern (credit the AI Objectives Institute, surfaced via Metagov's Deliberative Tools Gallery): themes with real quotes under them, prominence without erasure for minority views, percent agreement by opinion group where we have votes, a who-was-heard section that names who was not, and a one-paragraph plain-language summary for the next flyer. Import the results JSON a listening wall exports; export the report as JSON too so an assembly can use it as its briefing. Add a printable one-page summary (materials/summary.html).
