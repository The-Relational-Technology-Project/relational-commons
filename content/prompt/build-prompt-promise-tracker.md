# Promise Tracker dashboard build prompt

> Build a public dashboard tracking elected officials' commitments and follow-through.

Build a public dashboard that lists specific commitments made by local officials, their status (kept, broken, in progress), the source, and the date, with a simple way for residents to submit and cite new commitments.
