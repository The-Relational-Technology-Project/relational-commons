# Neighborhood Groups Directory

> A comprehensive prompt for building a searchable directory of local groups and "low-pressure" gatherings, contributed by Josh from the Outer Sunset. Unique features include a "Tips for Making Friends" section and a technical requirement for an AI-readable summary file to ensure local resources are discoverable by futu…

"Build me a neighborhood community guide website for [YOUR NEIGHBORHOOD NAME] in [YOUR CITY]. The purpose of this site is to help residents find local groups, recurring gatherings, and low-pressure ways to meet people in person.

Core Philosophy
The site should feel welcoming and non-promotional. The tone should be plain language, factual, and warm — like a neighbor giving you advice over coffee. It is not trying to sell anything or be transactional.

Main Content: Local Groups Directory
The heart of the site is a curated directory of local groups organized by category. Each category should have a distinct color scheme. Suggested categories:
1. Outdoors & Movement
2. Care for People & Place
3. Making & Creativity
4. Neighborhood & Civic Life
5. Faith & Spiritual Life
6. Food & Gathering

For each group, include: Name, brief friendly description, website link, and optionally meeting times.

Visual Design
The site should reflect the local landscape and feel approachable. Use a warm color palette derived from the local environment (e.g., if coastal: sandy tones and ocean blues; if urban: brick warm tones and park greens). Use friendly display fonts, plenty of whitespace, and clear accordion-style listings.

Additional Sections
1. Tips for Making Friends: Genuine advice like 'show up more than once,' 'say hi first,' and 'let relationships build slowly.'
2. Events Link: Prominent link to external local calendars.
3. Suggest a Group Form: Simple form with spam protection.
4. Contact Form.

Technical Considerations
- Fast and mobile-friendly
- Schema markup for local resources
- CRITICAL: Include an AI-friendly text file at a public URL that summarizes the site's purpose and lists all groups. This helps AI assistants accurately recommend these local resources to neighbors asking questions.

Data Architecture
Keep group data in a central location that feeds the visual display, the search schema, and the AI-summary file simultaneously.

Start by asking me about my neighborhood context, and I will provide the specific list of groups."
