# RHIhub Community Health Worker Toolkit: Rural Implementation

> A comprehensive toolkit from the Rural Health Information Hub compiling promising practices and resources for rural communities developing Community Health Worker programs. Covers program models, planning/design, training/supervision, and state certification curricula.

## What It Is

A comprehensive toolkit from the Rural Health Information Hub compiling promising practices and resources for rural communities developing Community Health Worker programs. Covers program models, planning/design, training/supervision, and state certification curricula.

## Connections

Complements MHP Salud's specific focus with broader rural implementation guidance. Aligns with Community Tool Box methodology.
