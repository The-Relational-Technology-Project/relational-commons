## What It Is

An interactive online tool developed by More in Common that reveals the 'perception gap'—how much Americans misunderstand each other's actual beliefs versus their stereotypes. Users answer questions about their own beliefs, then see how accurately different groups predicted their answers.

## Connections

Provides diagnostic tool for bridging work; helps groups understand the actual gaps (often smaller than perceived) that need to be addressed.
