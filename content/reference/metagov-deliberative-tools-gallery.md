# Metagov's Deliberative Tools Gallery

> The source collection for this shelf: digital tools that go beyond basic voting and commenting, mapped across the governance cycle. Seventeen more tools beyond the ones featured here, each with its stages.

Curated by Metagov's Interoperable Deliberative Tools project (research directors Liz Barry, Aviv Ovadya, Amy Zhang, Joshua Tan, Eugene Leventhal). Stages verbatim from the gallery's cards.

More in the gallery, by stage: Deliberative Canvas (reflecting); Ethelo (deliberating); Evocracy (deliberating); Global Brain Algorithm (deliberating); Go Vocal (deliberating); Harmonica (framing, eliciting, deliberating); Interoperable Co-operative Governance (framing, deliberating, deciding); Iswe Foundation (framing, eliciting); Ize (eliciting); Micropublishing (learning); Moral Graph Elicitation (eliciting); Pairwise (deciding); PolicyCraft (deliberating, eliciting, reflecting); Power Ranker (eliciting, reflecting, deciding); Stanford Participatory Budgeting Platform (deciding); Swarmcheck (framing, learning, deliberating); Voice to Vision (eliciting).

When a build borrows a pattern, name the tool and its builders in the plan and in the app's about or credits. Attribution travels.
